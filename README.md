## Featured Projects

### 🎵 DevBeats — Custom Local Music Engine
A fully custom-built music player powered by vanilla JavaScript, with no external audio libraries.

- Asynchronously scans local audio folders and metadata using the Fetch API and `async/await`
- Custom-built audio controller: seekbar, play/pause, track navigation, real-time duration updates, and volume control
- Multi-playlist library — switch between album folders dynamically without page reloads
- Responsive dark-mode UI built with HTML5 and CSS Flexbox, including a mobile drawer view

**Tech:** HTML5, CSS3, Vanilla JavaScript (ES6+), Fetch API, DOM Manipulation

### 🎬 Mov-es — Movie Discovery Web App
A movie discovery platform that fetches real-time data from the TMDB API and presents it through a clean, card-based UI.

- Displays detailed movie information including ratings, overview, and metadata
- Card-based responsive layout for easy browsing

**Tech:** JavaScript, TMDB API, HTML, CSS
**Repo:** [github.com/KJEmpireE07/mov-es-movie-app](https://github.com/KJEmpireE07/mov-es-movie-app)
